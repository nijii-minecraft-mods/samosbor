# Samosbor (Самосбор) — Minecraft Fabric 1.21.1 Mod

Постсоветский хтонический хоррор-мод по вселенной **«Самосбор»** для Minecraft Fabric 1.21.1 с использованием библиотеки **Polymer**.

> [!NOTE]
> Мод является **100% серверным**. Игроки могут подключаться к серверу (или играть в одиночной игре) с **чистого ванильного клиента Minecraft 1.21.1** без установки каких-либо модов!

---

## 🏗️ Особенности мода

* **Бесконечная «Гигахрущёвка» высотой 1024 блока**:
  * Кастомное измерение `samosbor:gigakhrushchyovka` с высотой в **1024 блока** (свыше **170 этажей**).
  * Плотный фиолетово-пепельный хтонический туман, давящая тишина и пещерные звуки.
  * Монолитный железобетонный потолок на Y=1020..1024 и фундамент из бедрока на Y=0..2.
* **Детальный процедурный генератор (`GigakhrushchChunkGenerator`)**:
  * Сетка коридоров с типовой двухцветной отделкой (казённая краска внизу, побелка вверху).
  * Вертикальные лестничные подъезды, соединяющие этажи сверху донизу.
  * Лифтовые шахты с оборванными цепями.
  * Жилые ячейки (квартиры граждан) с кроватями, ящиками с советским лутом.
  * Заводские цеха высотой в 2–3 этажа с колоннами и пищевыми синтезаторами (производство аппарата ЖП-11-У).
  * Карантинные мёртвые зоны: залитые монолитным бетоном или заросшие хтонической биомассой, слизью и ядовитыми мухоморами.
* **Заброшенные хрущёвки в Обычном мире (Overworld)**:
  * В биомах верхнего мира генерируются 5-этажные панельные дома серии П-46.
  * В подъезде расположен лифт: зайдя в него, игрок слышит лязг тросов, погружается в темноту и переносится в Гигахрущёвку.
* **Катастрофическая аномалия «Самосбор» (`SamosborManager`)**:
  1. **Предвестие**: мерцание ламп, скачки напряжения, запах озона и сырого мяса.
  2. **Тревога**: оглушительный вой сирен ГО, клубы ядовитого фиолетового тумана из решеток вентиляции.
  3. **Пик аномалии**: коридоры затоплены ядовитым фиолетовым туманом. Любой игрок вне загерметизированной комнаты и без противогаза ГП-5 задыхается и получает урон. В чате раздаются жуткие шепоты мимиков (*«Открой дверь... это Валера... здесь холодно...»*), спавнятся порождения Самосбора.
  4. **Отбой**: сирены смолкают, туман оседает.
* **Полимерный контент (отображается на ванильных клиентах)**:
  * **Блоки**: Бетонная панель П-46, Облезлая казённая панель, Гермодверь с поворотным вентилем (правый клик закрывает и закручивает затвор, изолируя от тумана), Аварийная красная лампа, Люминесцентная лампа, Панель вызова лифта, Пищевой синтезатор, Хтоническая биомасса, Токсичный мухомор.
  * **Предметы**: Пищконцентрат (сытный паёк), Талон на пайку, Противогаз ГП-5 (защищает дыхание от тумана), Огнемёт Ликвидатора (стреляет огнём), Деталь ЖП-11-У, Монтировка-лом (взламывает заблокированные двери).

## ⌨️ Команды

* `/samosbor travel` (или `/gigakhrushch`) — телепортация в Гигахрущёвку и обратно.
* `/samosbor status` — статус текущей фазы Самосбора и таймера.
* `/samosbor trigger <warning|escalation|peak|recession|calm>` — принудительный запуск фазы аномалии.
* `/samosbor stop` — сброс аномалии в спокойный режим.

## 🛠️ Сборка из исходников

Требования: **Java 21**.

```bash
git clone https://github.com/perdub/samosbor.git
cd samosbor
./gradlew build
```

Собранный jar-файл будет находиться в `build/libs/samosbor-1.0.0.jar`.
