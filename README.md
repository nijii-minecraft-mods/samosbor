# Samosbor (Самосбор) — Minecraft Fabric 1.21.1 Mod

Постсоветский хтонический хоррор-мод по вселенной **«Самосбор»** (samosbor.online) для Minecraft Fabric 1.21.1 с использованием библиотеки **Polymer 0.9.x**.

> [!IMPORTANT]
> Мод является **100% серверным**. Игроки подключаются с **чистого ванильного клиента Minecraft 1.21.1** без установки каких-либо модов! Все кастомные блоки (3D головы бытовой техники, гермодвери), звуки, предметы и сущности рендерятся средствами Polymer.

---

## 🏗️ Особенности мода

* **Бесконечная «Гигахрущёвка» высотой 1024 блока (170 этажей)**:
  * Кастомное измерение `samosbor:gigakhrushchyovka` с высотой в **1024 блока**.
  * Плотный фиолетово-пепельный хтонический туман, давящая тишина и эмбиент мегаструктуры.
  * Монолитный железобетонный потолок на Y=1020..1024 и фундамент из бедрока на Y=0..2.
* **Гауссово распределение телепортации лифта**:
  * Вход через шахту лифта в Обычном мире распределяет игрока по нормальному закону ($\mu = 85, \sigma = 30$, этажи 2–165).
  * ~69% шанса появиться в безопасном жилом ярусе, ~27% — в промышленных или лабораторных этажах, ~4% — аварийное падение в затопленные трюмы реакторов или на верхние уровни Парткома.
* **Служебное метро и ступенчатые лестницы**:
  * Метрополитен на этажах 3, 43, 83, 123 со станциями типа «сороконожка», энергорельсами и гермоворотами В-1.
  * Ступенчатые лестничные марши (по 13–23 этажа), вынуждающие выходить в коридоры для поиска следующих переходов.
  * 4 типа вертикальных «дворов-колодцев» (4x4, 8x8, 12x12 и террасные).
* **34 варианта помещений и макро-структуры**:
  * Советские квартиры, коммуналки, убежища выживших, самогонные самогонщиков.
  * **Советская школа / кабинет НВП**: парты, химическая доска, плакаты ГО, аптечка.
  * **Актовый зал / Кинолекторий**: ряды кресел, сцена с алым занавесом, трибуна.
  * **Спортивный зал**: шведские стенки, гимнастические маты, ящики со снаряжением.
  * **Оккультное святилище Биомассы**: алтарь плоти, свечи, черепа, сектантские манускрипты.
  * **Кратер термоочистки**: последствия зачистки термитом ликвидаторов.
* **Оккультная система: «Культ Великой Биомассы»**:
  * **Алтарь плоти (`cult_altar`)**: 3D блок с биением сердца Вардена. Поглощает пищу и регенерирует здоровье; сжигается огнемётом.
  * **Молитвенник Биомассы (`biomass_grimoire`)**: Умиротворяет монстров или ранит владельца для призыва ловушек из биомассы.
  * **Костяной серп Ликвидации (`ritual_sickle`)**: Наносит кровотечение и мгновенно срезает биомассу.
  * **Оккультный тотем из сухожилий (`cult_totem`)**: Защищает во второй руке от удушья Самосбора ценой прочности и галлюцинаций.
* **Расширенный бестиарий монстров**:
  * **Мини-босс «Валера / Древний Мимик»**: Вооружён огнемётом РОКС-3 и незеритовым шлемом. Дропает **«Сердце Биомассы»** и **«Именной жетон Ликвидатора: ВАЛЕРА»**.
  * **Сектант Биомассы**: Вооружён серпом и гримуаром, насылает споры и слепоту.
  * **Обезумевший Ликвидатор**: В пробитом противогазе, стреляет очередями из огнемёта или бросает хлор.
  * **Мясная пиявка**: Быстрый паразит из вентиляции и мусоропроводов.
* **Полное дерево достижений (Advancements)**:
  * 16 уникальных достижений в 4 ветвях:
    * *Выживание и ГО*: «Вентиль закручен», «Сварка намертво», «Пережить сирену», «Ресурс фильтра».
    * *Быт и Собирательство*: «Синий огонёк», «Хрущёвская слеза», «Синяя изолента», «Посылка из мусоропровода».
    * *Радиоэфир и Архивы*: «Номерная станция», «Слушай стены», «Секретная папка», «Фон в норме».
    * *Бой и Хтонь*: «Очистное звено», «Еретический алтарь», «Валера, выходи!».
* **Арсенал выживания и механики**:
  * Газовый резак РГ-3: заваривание гермодверей ацетиленом АЦ-5 и срезка швов.
  * Газовая плита «Лысьва» и варка горячего борща.
  * Дозиметр ДП-5В с индикатором и щелчками Гейгера.
  * Слуховая трубка СТ-4 для акустической разведки стен.
  * Магнитные кассеты МК-60 и радиоприёмник «ВЭФ-202» с частотами ГО и УВБ-76.

## ⌨️ Команды

* `/samosbor travel` (или `/gigakhrushch`) — телепортация в Гигахрущёвку и обратно.
* `/samosbor status` — статус текущей фазы Самосбора и таймера.
* `/samosbor trigger <warning|escalation|peak|recession|calm>` — принудительный запуск фазы аномалии.
* `/samosbor stop` — сброс аномалии в спокойный режим.

## 🛠️ Сборка из исходников

Требования: **Java 21**.

```bash
git clone https://github.com/perdub/samosbor.git
cd samosbor
./gradlew build --no-daemon
```

Собранный jar-файл находится в `build/libs/samosbor-1.0.0.jar`.
